# NOS

Next OS — a customized, riced Ubuntu desktop inspired by Omakub.

**Supported:** Ubuntu **24.04 LTS** (Noble) and **26.04 LTS** (Resolute), GNOME desktop, x86_64.

Fresh installs recommended. On 26.04, GNOME is Wayland-only; NOS install scripts account for that (gsettings for idle/blanking, `gdctl` for Framework display detection, Ghostty from universe when available).
